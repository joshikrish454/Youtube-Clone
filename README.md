# Youtube-Clone

A simple YouTube homepage clone built with HTML, CSS, and JavaScript. The project recreates the basic YouTube layout using Flexbox, including a header, sidebar, search bar, categories, and video cards. Clicking a video opens the corresponding YouTube video in a new tab.

Technologies:
HTML
CSS
JavaScript
Flexbox
Features
YouTube-style homepage
Responsive layout
Hard-coded video cards
YouTube video links
Sidebar navigation
Simple menu toggle
